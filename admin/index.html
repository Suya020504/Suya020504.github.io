GitHub 토큰으로 로그인하면 수상·프로젝트·보도·교육 항목을 직접 등록하고 고치고 지울 수 있어요. 저장하면 자동으로 빌드·검사·배포됩니다.

토큰은 어떻게 만드나요?
  1. GitHub에 Suya020504 계정으로 로그인한 브라우저에서 새 토큰 만들기를 여세요 (로그인 안 된 브라우저에서는 404가 떠요)
  2. Repository access: Only select repositories → portfolio-site 하나만 선택
  3. Permissions → Repository permissions → Contents: Read and write (다른 권한은 필요 없어요)
  4. 만든 토큰을 위 칸에 붙여 넣으세요. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다(GitHub API만 사용).
